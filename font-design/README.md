# Pembina Events — Font Design

## Current Site Colors
- Dark: `#0f172a`
- Primary: `#2563eb`
- Secondary: `#7c3aed`
- Light: `#f1f5f9`
- Muted: `#64748b`

## Font Pairing Options

### Option 1: Modern Clean (Current)
- **Heading:** Candara.ttf
- **Body:** Calibri.ttf
- **Rationale:** Matches current site aesthetic; Candara for headings, Calibri for body
- **Vibe:** Friendly, modern, highly legible

### Option 2: Classic Trust
- **Heading:** ACaslonPro-Bold.otf
- **Body:** Georgia.ttf
- **Rationale:** Serif authority for community trust; Georgia for readability
- **Vibe:** Established, trustworthy, traditional

### Option 3: Bold Impact
- **Heading:** Impact.ttf
- **Body:** SegoeUI.ttf
- **Rationale:** High-impact headlines; SegoeUI for clean body text
- **Vibe:** Attention-grabbing, modern, energetic

## Recommendation
For a community events site, **Option 1 (Modern Clean)** or **Option 2 (Classic Trust)** work best:
- Modern Clean maintains current brand consistency
- Classic Trust adds authority and gravitas for a community-focused site
