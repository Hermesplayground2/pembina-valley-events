AI Automation — Live Workflows

Viktor Boehm · Pembina Valley, Manitoba

runs locally on Ollama zero API cost per run n8n + OpenAI-compatible endpoint

1 · Support Triage

Answer support questions from a knowledge context, and route by confidence.

Webhook→ Local LLM→ Confidence gate→ auto-send / review
Endpoint
POST /webhook/ai-support-triage
Request
{"message":"What time does the Harvest Supper start?",
 "context":"Pembina Valley Harvest Supper:
            2026-11-28 at 17:30, Morden Community Hall."}
Live response — in context
{"status":"auto_send","reply":"17:30","confidence":1}
Live response — not in context
{"status":"review_queue",
 "reply":"The context does not provide information about the Wi-Fi password.",
 "confidence":0.1}

2 · Event → Social Post

Turn event details into ready-to-post copy with hashtags.

Webhook→ Local LLM→ JSON out
Endpoint
POST /webhook/event-to-post
Request
{"title":"Pembina Valley Harvest Supper",
 "date":"2026-11-28","time":"17:30",
 "location":"Morden Community Hall, 500 Stephen St",
 "details":"Potluck supper, live music, free admission."}
Live response
{"status":"ok","char_count":174,
 "post":"Join us for the Pembina Valley Harvest Supper on
         November 28 at 5:30 PM at Morden Community Hall.
         Enjoy a potluck supper and live music by the Valley
         Strings. Free admission.",
 "hashtags":"#PembinaValley #HarvestSupper #CommunityHall"}

3 · Batch Classify → JSON + CSV

Classify a whole batch of rows in one call, with structured and CSV output.

Webhook→ Local LLM→ JSON + CSV
Endpoint
POST /webhook/batch-classify
Request
{"instruction":"Classify each business as restaurant,
                 retail, service, or other.",
 "items":[{"id":"1","text":"Pembina Co-op Farm Supplies"},
          {"id":"2","text":"Bobs Diner on Main Street"},
          {"id":"3","text":"Denray Tire and Auto"},
          {"id":"4","text":"Willow Rock Farms"}]}
Live response (trimmed)
{"status":"ok","count":4,
 "results":[
  {"id":"1","label":"retail","reason":"farm supplies store"},
  {"id":"2","label":"restaurant","reason":"a diner"},
  {"id":"3","label":"service","reason":"tire and auto services"},
  {"id":"4","label":"other","reason":"a farm"}],
 "csv":"id,label,reason\n1,retail,...\n2,restaurant,..."}
Honest notes. These three endpoints run on a local n8n instance on the LAN and are not reachable from the public internet; the responses above are real captured output from live calls, not mockups. The model behind all three is a local qwen3:8b — so per-run inference cost is zero, and the trade-off is that a small local model is weaker than a frontier one for open-ended generation. The confidence gate in workflow 1 exists precisely because of that.
