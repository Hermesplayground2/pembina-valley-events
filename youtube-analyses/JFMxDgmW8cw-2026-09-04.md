## Transcript Summary
- Core claim: Hermes only becomes useful when repeated work becomes workflows.
- 6 workflows:
  1. Morning Command Center - daily priority check-in, suggests tasks, creates task list/Kanban/reminders
  2. Memory Wiki - searchable continuity for decisions/sessions/skills; avoids context-window bloat
  3. Content Intelligence - evidence-first ideation: check posted content, pipeline, competitors, outliers, analytics, transcripts, then pitch ideas
  4. Long-Running Goals (/goal) - meta-prompt first: success criteria, constraints, files, tools, deliverables, safety rules, verification
  5. Mission Control / Dashboard - Vercel dashboard for outputs, tasks, memory, scheduled jobs; Google-gated, approval-only risky actions
  6. Skill Building Loop - every correction updates the skill; task → artifact → correction → skill improvement
- Live demo: built a Telegram client-sentiment bot via /goal in under 1 hour with scoring, cadence rules, and read-only safety
- Comparison: same YouTube idea prompt on ChatGPT vs Hermes with Nova skill shows skill-augmented evidence vs generic guesswork
- Key insight: "If you only use Hermes as a chat window, it will still be useful, but if you build workflows around the work you repeat, it becomes something different"
