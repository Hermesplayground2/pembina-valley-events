## Transcript Summary
- Core claim: Build a full multi-agent Jarvis dashboard on top of Hermes with voice, keyboard shortcuts, scheduling, and external integrations
- Crew/agents:
  - Jarvis - boss agent, orchestrates, reports to user in plain terms
  - Dev - code, building tools, fixing bugs, sandboxed projects
  - Research - live web digging, market checks, competitor research, real-sourced facts
  - Assistant - personal assistant, reads email/calendar, drafts but never sends/deletes without approval
- Dashboard features:
  - Mission control homepage with agent workload distribution
  - Agent statistics, token usage, activity log
  - Schedule tab for cron jobs with run/pause/delete controls
  - Library tab for long-form markdown documents from agents
  - Research agent uses SE API instead of raw web search to avoid captures/HTML parsing
  - Voice control via local transcription + Kokoro TTS or paid option
  - Keyboard shortcuts 1-4 to switch between agents
  - Composio integration for Gmail/Google Calendar read-only access
  - Tailscale bind for dashboard access without SSH tunneling
- Key architectural points:
  - Each agent has its own soul.md/profile
  - Telegram routing via tree plugin with separate topics per agent
  - Approval gates for sending/publishing
  - Long-form outputs go to library tab, not chat, to avoid context bloat
- Demo highlights:
  - Voice commands to turn on office lights via Home Assistant
  - Morning briefing with unread emails, weather, calendar
  - Focus time block auto-scheduled on calendar
  - Research agent does live competitor analysis
  - Token usage visible per agent
- Tools used in build:
  - Claude Code for implementation prompts
  - SE API for search
  - Composio for app integrations
  - Tailscale for VPN/remote access
  - Kokoro for local TTS
